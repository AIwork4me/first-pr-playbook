# 初学者术语速查

| 术语 | 只记住这一句话 | 去哪一课学习 |
|---|---|---|
| Repository / Repo | 一份可协作的代码仓库 | [01](../../lessons/zh-CN/01-find-an-issue.md) |
| Issue | 一张描述问题/任务的公开工单 | [01](../../lessons/zh-CN/01-find-an-issue.md) |
| Reproducer | 让别人用尽可能少的步骤看到相同问题 | [02](../../lessons/zh-CN/02-reproduce-a-bug.md) |
| RCA / Root Cause | 找到问题发生的真正原因，而非仅看到报错 | [03](../../lessons/zh-CN/03-root-cause-analysis.md) |
| Minimal Patch | 只修复必要部分，不顺手大规模重构 | [04](../../lessons/zh-CN/04-minimal-patch.md) |
| Regression Test | 防止已修复的 Bug 再次出现的测试 | [05](../../lessons/zh-CN/05-prove-the-fix.md) |
| A/B 对照 | 在可比较条件下，对照修改前后行为 | [05](../../lessons/zh-CN/05-prove-the-fix.md) |
| Fork | 把别人的仓库复制到自己账号名下以便贡献 | [06](../../lessons/zh-CN/06-open-first-pr.md) |
| Branch | 仓库中用于隔离修改的开发分支 | [06](../../lessons/zh-CN/06-open-first-pr.md) |
| Commit | 一次有明确含义的变更快照 | [06](../../lessons/zh-CN/06-open-first-pr.md) |
| PR / Pull Request | 提议把你的代码合并到目标分支，等待审阅 | [06](../../lessons/zh-CN/06-open-first-pr.md) |
| Upstream / 上游 | 你向其提议修改的官方项目（相对于你的 Fork 而言） | [06](../../lessons/zh-CN/06-open-first-pr.md) |
| Baseline / 基线 | 用来与修复版本对照的、未修复的代码状态 | [05](../../lessons/zh-CN/05-prove-the-fix.md) |
| Review | 维护者对代码、测试、设计的审阅反馈 | [08](../../lessons/zh-CN/08-handle-review.md) |
| CI | 自动运行的格式检查、构建和测试工作流 | [09](../../lessons/zh-CN/09-debug-ci.md) |
| Merge | 上游正式接受 PR 的代码变更 | [10](../../lessons/zh-CN/10-merge-and-handoff.md) |
| SKIP | 测试条件不满足而跳过；**不等于 PASS** | [05](../../lessons/zh-CN/05-prove-the-fix.md) |
