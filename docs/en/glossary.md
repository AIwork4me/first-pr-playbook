# Beginner Glossary

| Term | The one sentence to remember | Learn it in |
|---|---|---|
| Repository / Repo | A collaborative code store with public history | [01](../../lessons/en/01-find-an-issue.md) |
| Issue | A public ticket describing a problem or task | [01](../../lessons/en/01-find-an-issue.md) |
| Reproducer | The fewest steps that let someone else see the same problem | [02](../../lessons/en/02-reproduce-a-bug.md) |
| RCA / Root Cause | The real reason a failure happens — not just where it's reported | [03](../../lessons/en/03-root-cause-analysis.md) |
| Minimal Patch | Fix only what's necessary; no drive-by refactoring | [04](../../lessons/en/04-minimal-patch.md) |
| Regression Test | A test that keeps a fixed bug from coming back | [05](../../lessons/en/05-prove-the-fix.md) |
| A/B Comparison | Comparing before/after behavior under comparable conditions | [05](../../lessons/en/05-prove-the-fix.md) |
| Fork | Your account's copy of someone else's repository, for contributing | [06](../../lessons/en/06-open-first-pr.md) |
| Branch | An isolated line of development inside a repository | [06](../../lessons/en/06-open-first-pr.md) |
| Commit | A snapshot of related changes with a message | [06](../../lessons/en/06-open-first-pr.md) |
| PR / Pull Request | A proposal to merge your branch into the target branch, pending review | [06](../../lessons/en/06-open-first-pr.md) |
| Upstream | The official project you propose changes to (as opposed to your fork) | [06](../../lessons/en/06-open-first-pr.md) |
| Baseline | The unpatched code state you compare your fix against | [05](../../lessons/en/05-prove-the-fix.md) |
| Review | Maintainer feedback on code, tests, and design | [08](../../lessons/en/08-handle-review.md) |
| CI | Automated format/build/test workflows that run on PRs | [09](../../lessons/en/09-debug-ci.md) |
| Merge | Upstream formally accepting a PR's changes | [10](../../lessons/en/10-merge-and-handoff.md) |
| SKIP | A test skipped because its preconditions were missing — **not a PASS** | [05](../../lessons/en/05-prove-the-fix.md) |
| HIPRTC / MIOpen | ROCm's runtime GPU compiler / deep-learning compute library | [Case study](../../case-studies/en/rocm-pr-13437.md) |
