# Mission 01｜筛选 Issue

[第 01 课](../../lessons/zh-CN/01-find-an-issue.md) · [模板：Issue 选择卡](../../templates/zh-CN/issue-selection.md) · [English version](../en/mission-01-find-an-issue.md)

**任务（Mission）.** 在一个目标仓库中找出三个真实、适合新手的 Issue，选定一个主目标和一个备选——全程不修改任何东西。

**背景（Context）.** 这是第一次开源贡献。助手扮演调研队友；所有选择和对外沟通由人类完成。

**输入（Inputs）.** `[GITHUB_REPO_URL]`——一个来自你实际使用的软件的仓库。

**约束（Constraints）.**

- 只读：不修改文件、不提交、不发帖。
- 引用的每个 Issue 必须能通过 URL 在 GitHub 核实；绝不依赖回忆的编号。
- 遵守仓库 CONTRIBUTING.md 及其认领流程。

**步骤（Steps）.**

1. 阅读仓库 README、CONTRIBUTING.md 和开放 Issues。
2. 提出三个候选。每个给出：URL、用户预期与实际、复现所需环境、需要的知识、是否有人正在处理、应先向维护者确认什么。
3. 排序：推荐最清楚、范围最小的作为主目标，一个作为备选，理由以证据陈述。

**验证（Validation）.** 每个 Issue URL 可在 GitHub 打开；预期/实际描述与原文一致；快速检查未发现重复 PR 或认领者。

**交付（Deliverables）.** 主目标（可含备选）的完整 [Issue 选择卡](../../templates/zh-CN/issue-selection.md)。

**停止条件（Stop conditions）.** 出现以下情况即停下并报告：仓库 CONTRIBUTING.md 不接受临时贡献；候选 Issue 都缺少可核实细节；或所需环境（如特定 GPU）人类不具备——此时改为推荐其他仓库。
