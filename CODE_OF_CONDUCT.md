# Code of Conduct

[简体中文](CODE_OF_CONDUCT.zh-CN.md)

We welcome contributors of every experience level and language background. This community encourages questions, reproducible experiments, kind corrections, and honest statements of validation boundaries.

- Discuss code and evidence, never a person's ability or identity.
- Respect maintainer time: be specific, search before repeating, avoid nagging and flooding.
- Do not demean anyone for using — or not using — AI tools; every contributor answers for the correctness of what they submit.
- Do not post private data, credentials, harassment, or inappropriate content.

Maintainers may ask for edits, pause an interaction, or limit collaboration access when these rules are violated. General questions can go through GitHub issues; anything involving private information must not be posted publicly — use the private contact channel on the maintainer's GitHub profile page instead.

This project adapts the spirit of common open-source conduct standards (kindness, evidence, respect for maintainer time) rather than adopting a foundation text verbatim.
