# 课程目录 — 简体中文

**[English version](../en/README.md)**

十篇教程，每课一个技能、一个可检查的成果。每一课的输出是下一课的输入。

| 课次 | 课程 | 技能 | 成果模板 |
|---|---|---|---|
| 01 | [找 Issue](01-find-an-issue.md) | 选择真实、适合自己的问题 | [Issue 选择卡](../../templates/zh-CN/issue-selection.md) |
| 02 | [复现 Bug](02-reproduce-a-bug.md) | 复现并记录故障 | [最小复现报告](../../templates/zh-CN/bug-reproduction.md) |
| 03 | [根因分析](03-root-cause-analysis.md) | 用证据定位根因 | [RCA 记录](../../templates/zh-CN/rca.md) |
| 04 | [最小修复](04-minimal-patch.md) | 设计最小必要修改 | [Patch Plan](../../templates/zh-CN/patch-plan.md) |
| 05 | [验证修复](05-prove-the-fix.md) | A/B 对照与回归测试 | [验证矩阵](../../templates/zh-CN/validation-matrix.md) |
| 06 | [首次 PR](06-open-first-pr.md) | 安全完成 Fork/分支/提交/推送/PR | 一个真实的 PR 链接 |
| 07 | [PR 描述](07-write-pr-description.md) | 让 PR 可审查 | [PR 描述模板](../../templates/zh-CN/pr-description.md) |
| 08 | [处理 Review](08-handle-review.md) | 用证据回应反馈 | [Review 闭环表](../../templates/zh-CN/review-response.md) |
| 09 | [处理 CI](09-debug-ci.md) | 正确归因 CI 失败 | [CI 排查表](../../templates/zh-CN/ci-triage.md) |
| 10 | [Merge 与交付](10-merge-and-handoff.md) | 专业收尾并沉淀记录 | [作品集记录](../../templates/zh-CN/portfolio-handoff.md) |

每课均链接对应的 CodeX 任务（[prompts/zh-CN/](../../prompts/zh-CN/README.md)）与英文版课程。第一次来？先用 [15 分钟入门实验](../../labs/first-fix/README.zh-CN.md)完成一次保底的成功体验，再读[从这里开始](../../docs/zh-CN/start-here.md)；进入第 02 课前，先完成 [Git 速成](../../docs/zh-CN/git-quickstart.md)。
