Ten lessons, one skill and one verifiable deliverable each. Each lesson's output feeds the next.

| # | Lesson | Skill | Deliverable |
|---|---|---|---|
| 01 | [Find an issue](01-find-an-issue.md) | Choose a real, suitable issue | [Issue selection card](../../templates/en/issue-selection.md) |

| 03 | [Root-cause analysis](03-root-cause-analysis.md) | Locate the root cause with evidence | [RCA record](../../templates/en/rca.md) |
| 04 | [Minimal patch](04-minimal-patch.md) | Design the minimal necessary change | [Patch plan](../../templates/en/patch-plan.md) |
| 05 | [Prove the fix](05-prove-the-fix.md) | Validate with A/B + regression tests | [Validation matrix](../../templates/en/validation-matrix.md) |
| 06 | [Open your first PR](06-open-first-pr.md) | Fork/branch/commit/push/PR safely | A real PR URL |
| 07 | [Write the PR description](07-write-pr-description.md) | Make the PR reviewable | [PR description](../../templates/en/pr-description.md) |
| 08 | [Handle code review](08-handle-review.md) | Respond to feedback with evidence | [Review response table](../../templates/en/review-response.md) |
| 09 | [Debug CI](09-debug-ci.md) | Attribute CI failures correctly | [CI triage record](../../templates/en/ci-triage.md) |
| 10 | [Merge and handoff](10-merge-and-handoff.md) | Close out and keep the record | [Portfolio record](../../templates/en/portfolio-handoff.md) |
