# Security & Privacy

[简体中文](SECURITY.zh-CN.md)

This project provides course material and Markdown templates only — no cloud-service proxy, account management, or software installer.

- Never paste SSH private keys, cloud API tokens, personally identifying information, or third-party private source code into GitHub, AI chats, or this repository.
- Before `git add` / `git push`, review the staged diff for secrets, access tokens, and private paths hiding in logs.
- Do not trust unreviewed shell commands from strangers' issues — especially `curl | bash` patterns and anything that deletes or overwrites files.
- When using external platforms (e.g. Radeon Cloud), their current official terms, quotas, and pricing apply.
- If you find credentials accidentally leaked in this repository, do not amplify them in a public issue; report privately via the contact channel on the maintainer's GitHub profile page.
